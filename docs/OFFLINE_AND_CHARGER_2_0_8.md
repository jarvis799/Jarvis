# JARVIS 2.0.8

- Failed run 41269888928 stopped because HolographicHudPreferencesTest checked the v4 migration marker while production now writes v5. The assertion now checks the current migration; data-preservation and later-choice tests remain enabled.
- Settings → Premium · Offline AI Models opens the free model catalogue. Recommended Gemma 4 E2B Q4_K_M is pinned to upstream revision and SHA-256 (3,106,738,272 bytes). E2B is 2.3B effective / 5.1B including embeddings, not a 2 GB file.
- llama.cpp is pinned to commit 8642541b255bfb5dc39cd351a178be09013a55d6 with Gemma 4 support. The text-only JNI prompt follows the official no-thinking template. Image, video, audio and model-generated tool calls are not wired to this local path.
- Choose a local Documents/Downloads or SD-card folder before downloading. The verified download is automatically copied there; setup then checks free RAM and actually generates a reply before activation. A private runtime copy is required for native file access, so allow space for both copies.
- Uninstall removes app-private data and Android document grants, NOT the selected shared-folder file. Reinstall → Import saved GGUF → select that file → verification and automatic setup. No model download is needed. Unknown imports have format/runtime checks but no authenticated publisher checksum.
- Application battery monitoring announces connected/charging, full and unplugged transitions once each. Initial sticky battery state is silent. The existing running assistant process/foreground service is required; force-stop and manufacturer battery restrictions can prevent announcements.
- Accepted user transcriptions go through bundled ML Kit language identification until the first supported identifiable language is found while language is Auto. Explicit language settings are respected. Short/ambiguous utterances may require another sentence.
- Android TTS synthesizes and saves local WAV phrases; no microphone recording is made for the cache. Subsequent events replay the audio. Hindi, English, Bengali and the other selectable languages have localized phrases; the phone must have a functioning TTS voice for the selected language. Missing voices/errors appear on the model page.
- Release workflow no longer disguises a failed release as a debug APK. It verifies both bundled engine ABIs and the permanent signing certificate before publishing the APK for the exact commit.
- Full-app liquid-glass redesign is NOT complete. Existing UI is preserved except the requested settings entry and model/charger page additions. Device inference performance, voice quality and OEM background behavior require physical-device checks.
