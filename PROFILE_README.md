## About

I'm **Arian Ahamed Ayan**, known online as **DEV ARIYO** — a junior full-stack developer who builds for the web and for Android.

My work sits where clean interface design meets practical engineering: static sites and marketing pages, data-driven web applications, Android applications, interactive browser experiences, and AI-powered developer tools that remove repetitive work from the build process.

I care about fast load times, readable code, restrained visual design and interfaces that behave the same on a phone as they do on a desktop.
